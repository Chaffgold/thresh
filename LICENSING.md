# Data & model licensing / attribution

The `flight-data-training-pipeline` consumes two external flight-data sources
with different redistribution terms. This document records the project's posture
(design Decision 13). The thresh source code itself is licensed under
`MIT OR Apache-2.0` (see the workspace manifest).

## OpenSky Network — primary training source (redistributable)

- **Use:** historical state vectors via the public REST endpoint and the
  published Zenodo trajectory dumps (`python/acquisition/opensky.py`).
- **Terms:** the OpenSky Network data is available for academic / non-commercial
  use. A redistributable subset **may** ship with this repository and a fuller
  dataset on a public dataset host, with attribution.
- **Attribution:** *"This work uses data from the OpenSky Network"* — cite
  Schäfer et al., "Bringing up OpenSky: A large-scale ADS-B sensor network for
  research," IPSN 2014. See <https://opensky-network.org/>.
- **In this repo:** the checked-in `test-data/training/` samples are synthetic
  (generated by the Rust `gen-imm-dataset` / `gen-detector-dataset` binaries),
  not raw OpenSky records. The one real OpenSky-derived artifact is
  `test-data/trajectories/opensky-sample.parquet` (a small CI dry-run sample
  captured with `python -m acquisition.opensky_cli`); the attribution above
  applies to it and is recorded in its dataset metadata,
  `test-data/trajectories/README.md`.

## ADS-B Exchange v2 — live evaluation / edge cases (NOT redistributable)

- **Use:** real-time acquisition for evaluation and edge-case targets
  (military / blocked aircraft) via `python/acquisition/adsbx.py`.
- **Terms:** the ADS-B Exchange terms of service **forbid redistribution** of
  the raw feed. This repository ships only the acquisition *client*;
  reproduction requires a developer-supplied ADSBx API key
  (`ADSBX_API_KEY`, see `TRAINING.md`).
- **Do not commit ADSBx output to git.** Acquisition output lands under a
  developer-local `data/` tree, not in the repository.

## ADS-B is system-level truth, never a measurement

Both tracks treat ADS-B reports as **system/track-level truth** (aircraft
self-reported GPS state at ~1 Hz with identity), never as sensor measurements
(design Decision 4). Training measurements are *synthesised* from the truth
trajectory by `thresh-synth`; the IMM classifier trains on classical-tracker
filter outputs, not on raw ADS-B state. This keeps the training distribution
aligned with deployment.

## Trained models

Trained checkpoints (when produced) are released under the repository's license
(`MIT OR Apache-2.0`); their data lineage and OpenSky attribution are recorded
in `test-data/models/MODEL_CARD.md`.
