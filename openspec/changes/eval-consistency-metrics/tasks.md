# Tasks — Evaluation Consistency Metrics (NEES / NIS / GOSPA)

> Phases follow design.md's Migration Plan: the filter diagnostics land first (everything downstream consumes `UpdateOutcome`), then the eval-side math (chi-squared bounds before the accumulators that call them, per the phase-helper testing convention), then GOSPA (independent of the filter work — only needs `FrameData`), then the one tracker touch, then the benchmark schema and calibration last. Each phase is additive and independently revertible; the falsifiable exit criterion is task 7.2.

- [x] 1.2 Verify non-breakage: `cargo test --workspace` and `cargo clippy --workspace --all-targets -- -D warnings` pass with **zero edits** to the statement-position call sites (`tracker.rs:651`, `ecef_tracker.rs:255`, `cost_matrix.rs:200`, filter tests/benches, `thresh-py` wrapper) and all pre-existing filter tests keep their expected values (spec: "Existing callers are unaffected", "Existing CKF callers and tests are unaffected").
- [x] 1.3 KF/EKF diagnostics tests: linear KF outcome has `innovation = z − H·x_pred` and `S = H·P_pred·Hᵀ + R` against hand-computed values (spec: "Linear KF diagnostics match closed form"); EKF outcome matches `z − h(x_pred)` and `H_k·P_pred·H_kᵀ + R` at the predicted-state Jacobian (spec: "EKF diagnostics reflect the linearized update"); NIS of a zero innovation is exactly 0.
- [x] 1.4 UKF/CKF diagnostics tests: the returned S is bitwise the sigma-/cubature-point moment computed inside `update` (same computation, not a reconstruction), symmetric PD, and on a *linear* measurement model agrees with the KF's `H P Hᵀ + R` within sigma-point tolerance (spec: "UKF sigma-point S is exposed, not reconstructed"); CKF-vs-UKF parity on an identically initialised linear-Gaussian run — innovations within 1e-6, S within 1e-4 per element, mirroring the live posterior-parity tolerances (spec: "Diagnostics parity with UKF on a linear-Gaussian problem").
- [x] 1.5 Document the NEES/pre-first-update contract: doc comments state that predicted state/covariance are read from the `pub` `x`/`p` fields after `predict` and before `update` (no aliasing accessors), that diagnostics exist **only** as `update`'s return value (nothing stored, so no stale/pre-first-update query surface — spec: "Diagnostics validity is well-defined before any update"), and cross-reference KF's retained pre-update `innovation()` / `innovation_covariance()` gating helpers as "hypothetical residual for a candidate z", distinguishing them from the outcome of the update that happened.

## 2. Chi-squared bounds and NEES/NIS core — `thresh-eval/src/consistency.rs` (Decision 2)

- [x] 2.1 Implement the `chi2` submodule: Acklam inverse-normal, Wilson–Hilferty seed, Newton refinement on the regularized lower incomplete gamma (series/continued-fraction split, fixed iteration cap and tolerance — pure f64, no new deps; design Decision 2), and `two_sided_bounds(dof, alpha)` (default `alpha = 0.05`). Unit tests pin reference quantiles for dof 2, 4, 100, 400 — both tails — within 1% relative (spec: "Bounds match reference chi-squared quantiles"), verify the 99% interval widens correctly (spec: "Configurable confidence level"), and cover the small-dof lower-tail quantiles that a raw Wilson–Hilferty approximation misses (e.g. `χ²₂(0.025) = 0.0506`), documenting the seed-vs-refined error at the test site.
- [x] 2.2 Implement `nees(error, p) -> Option<f64>` and `nis(innovation, s) -> Option<f64>`: closed-form tests `e = [1, 2]`, `P = diag(1, 4)` → 2.0 with dof 2 (spec: "NEES matches the closed-form value") and `nu = [2]`, `S = [[4]]` → 1.0 (spec: "NIS matches the closed-form value"); singular covariance returns the explicit error value, never NaN/∞/panic (spec: "Singular covariance is rejected").
- [x] 2.3 Implement `ConsistencyAccumulator { sum, n, dof }` with `push` / `mean` / `verdict(alpha)` and the three-valued `ConsistencyVerdict` (Consistent / Overconfident / Underconfident), plus the per-track `HashMap<u64, ConsistencyAccumulator>` helper. Test: K = 100 samples at n = 4 judged against χ²(400)/100 bounds (spec: "ANEES aggregation over a track lifetime"); honest track A vs track B with covariances ×0.01 — per-track verdicts isolate B as overconfident (spec: "Per-track verdicts isolate the inconsistent track").
- [x] 2.4 Falsifiability bracket (Monte-Carlo, seeded): a linear KF with the true Q/R on a seeded linear-Gaussian trajectory (50+ runs or equivalent length) has ANEES *and* average NIS inside the two-sided 95% bounds; `Q × 0.01` drives ANEES above the upper bound (Overconfident); `Q × 100` drives it below the lower bound (Underconfident) (spec: "Consistent filter passes" / "Overconfident filter fails high" / "Underconfident filter fails low"). The NIS leg consumes `UpdateOutcome` streams with no ground-truth argument in any call (spec: "NIS from filter diagnostics only", "Diagnostics feed NIS directly", "CKF diagnostics feed NIS" — run the NIS leg through KF, UKF, and CKF).
- [x] 2.5 Determinism test: the same recorded error/innovation sequences evaluated twice in-process and across `cargo test` invocations produce bitwise-identical statistics, bounds, and verdicts — no hash-order dependence in the per-track path (iterate sorted IDs) (spec: "Repeated evaluation is bitwise identical").

## 3. NEES truth alignment — `EstimateFrame` + `sequence_anees` (Decision 3)

- [x] 3.1 Define `TrackEstimate { id, state, covariance }` and `EstimateFrame { gt, tracks }` in `consistency.rs` (`FrameData` untouched); export the interleaved position-index const `[0, 2, 4]`; implement `sequence_anees(frames, pos_idx, dist_threshold)` reusing the existing `match_frame` — project states via `pos_idx`, match Euclidean at the caller's threshold, compute position-marginal NEES (dof = 3) by inverting the extracted 3×3 position block of P. Doc comment states the population identity: NEES samples = MOTA true-positive pairs at the same threshold.
- [x] 3.2 `sequence_anees` tests: hand-built two-frame sequence with known error/covariance yields the hand-computed ANEES and sample count; an unmatched track and an unmatched truth contribute zero samples (matched-pairs-only, cardinality errors left to MOTA/GOSPA); a full-state estimate with correlated position/velocity gives position-marginal NEES from the marginal block, not from the inverse-of-full-P submatrix.
