# Tasks — Orbit Propagation Fidelity

> Phases follow design.md's Migration Plan: ephemerides first (third-body, SRP, and the H-P bulge all consume Sun/Moon positions), then force models one at a time with their consistency identities, then the adaptive integrator, then composition + goldens + the benchmark-invariance verification. Everything is additive — no existing force function, filter model, or benchmark default is edited. The falsifiable exit criterion is task 5.2.

## 1. Analytic ephemerides — `thresh-core/src/orbital/ephemeris.rs` (design Decision 5)

- [ ] 1.1 Implement the Meeus low-precision Sun series and the Vallado-lineage truncated Moon series, series coefficients transcribed from sources fetched at implementation time (cited inline, never from memory), producing ecliptic-of-date → MOD via mean obliquity → GCRF through `thresh_core::frames`; epochs are `Epoch`. Phase-helper decomposition; table-driven series loops.
- [ ] 1.2 Spot-value tests against fetched published values (Meeus worked examples and/or Vallado examples) plus structural tests (Sun ~1 AU, Moon ~384 Mm, ecliptic latitudes bounded). The end-to-end accuracy measurement against astropy lands with the golden generator (task 4.2), which records per-body angular-error tolerances in provenance (spec: "Analytic Sun and Moon ephemerides with measured accuracy").

## 2. Force models — `thresh-core/src/orbital/` (design Decisions 2–4)
